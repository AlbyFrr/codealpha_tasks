Welcome to my CodeAlpha Python Programming Internship repository. This project showcases a collection of practical Python applications developed during my internship, designed to demonstrate core programming concepts, data handling, and automation. The repository includes three primary projects: a classic Hangman Game utilizing string manipulation and game logic; a Portfolio Tracker that manages and monitors investment assets; and an automated Email Address Finder designed to parse and extract contact information from text blocks.

Each script highlights a commitment to writing clean, modular, and efficient Python code.
Hangman Game covers User input validation, string manipulation, and conditional game loops.
Portfolio Tracker covers Data tracking, basic financial math, and dictionary/list management.
Email Address Finder covers Regex, text parsing, and data extraction.
